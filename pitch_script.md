# Pitch Script

## 30-second opening

Agent-Ready Merchant OS helps AI agents discover products, make trustworthy purchase decisions, and complete checkout through a merchant-controlled API.

## The problem

Commerce APIs expose inventory and payments, but merchants still lack an AI-native operating layer for product context, recommendations, order status, and an auditable trail of agent actions.

## The solution

Our FastAPI and Next.js application gives agents structured product discovery, an AI shopping conversation, transparent upsells, Razorpay Test Mode checkout, and an audit log for every important action.

## Demo flow

1. Ask the merchant agent to find a product.
2. Show a relevant, explainable upsell.
3. Create a Razorpay Test Mode order.
4. Complete the test checkout.
5. Inspect the audit event generated by the agent.

## Closing

The result is a practical foundation for agentic commerce that uses public APIs, costs zero to prototype, and keeps the merchant in control.
